# ДЗ 3. Подборка вин

Приложение на Streamlit оценивает вино по его характеристикам. Можно проверить одно вино, загрузить список вин из CSV и посмотреть, как порог отбора влияет на результат.

## Запуск

Нужен Python 3.13. Выполни в папке `wine_app`:

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```
